  3. Emosi baru (6)

    bored · bosan
    pemicu: lama tanpa interaksi + energi sedang. Mata setengah, lirik malas.
    proud · bangga
    pemicu: aktivitas/permainan selesai. Mata naik, dagu terangkat.
    anxious · cemas
    pemicu: suara keras berulang, baterai rendah. Mata gelisah.
    relieved · lega
    pemicu: pulih dari sulk/jatuh. Kedip panjang lalu senyum.
    mischievous · usil
    pemicu: aktivitas play. Mata miring, lirik bergantian.
    lonely · kesepian
    pemicu: sendiri lama sebelum seek_social. Pandang ke pintu/pinggir.

    Tiap emosi: alias di canonical(), clip, cue, dan nama di dashboard/app.

  4. Variasi perilaku

    • Pola VariantPicker (4 varian anti-ulang) diperluas ke idle, aktivitas, dan reaksi suara.
    • Reaksi waktu: sambut pagi, protes begadang, bosan siang hari.
    • Reaksi kejadian: bangga setelah aktivitas, lega setelah sulk, usil saat main, cemas saat suara keras berulang.
    • Semua lewat RoboArbiter (tier Micro/Activity/Emotion) sehingga Safety dan Owner tetap menang.

  5. Verifikasi

    Host test (23 suite + uji pembeda emosi), build -Board both, git diff --check. Tampilan OLED fisik, latensi, dan suara tidak saya klaim lulus; dicatat sebagai uji perangkat tertunda di TASKS.md.

3 · Risiko & batasan

  • Flash C3 sudah 95 % (sisa ±81 KB); perubahan di S3 saja, jangan memindah BLE.
  • Cue suara baru memakai anggaran bunyi (RoboSoundBudget.h) dan jam tenang; perlu tidak membuat robot lebih berisik.
  • LivingEyes ada di luar repo (LivingEyes-merge); perubahan harus di-pin dan diuji build dulu.
  • Estimasi sentuh file: RoboEmotionMap.h, RoboBrain.h, RoboIdleActions.h, RoboTouchMood.h, SonicCue, RoboDesk .ino, tests, LivingEyes, pin.
